# XSTEP3 toolkit

Welcome to XSTEP3 toolkit version 3.5.1! For the original XSTEP3 documentation, see [1]. This repo is here only for historic reasons, as far as the XSTEP3 is now 30+ years old and, probably, long time dead... It was originally replaced by XSTEP4, back in the year 2k (see [2]) and both toolkits were designed to be easy to used and mimics the NeXTSTEP look and feel on X11. The XSTEP3 was born in the 90s, in a time when the X11 development was inhabited by dragons, which may reflect some X11 tutorials [3][4] and some experimental code, like the xstep3d:
